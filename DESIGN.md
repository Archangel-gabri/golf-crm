# DESIGN.md — Golf CRM v2 visual contract

> Главный анти-генерик приём. Заполнен ДО кода. Источник правды для верстки.
> Преподаватель/заказчик (Kidanov) должен с первого экрана увидеть **дорогой продукт**,
> а не «админку как у любой ИИшки». Токены — `design/tokens.json`.

## 0. Workflow note

Это **письменная фаза контракта**. Отдельными, отдельно одобряемыми этапами идут:
концепт-кадры (`assets/concepts/` через image-model), вживление токенов в
`tailwind.config.js`, миграция UI, визуальный QA. В этом патче — только контракт + токены.

**Стек-реальность:** остаёмся на **Vite + React 18 + Tailwind + TanStack Query**.
Применяем *принципы* premium-saas, **без переписывания на Next.js** (см. §9).

## 1. Суть и эмоция

- Продукт (1 фраза): операторский «кокпит» для управления гольф-клубом день в день.
- Главная эмоция первого экрана: **доверие + премиум** (спокойная уверенность), вторично — **скорость**.
- «Готово» = менеджер проводит полный день бронирований без трения, и это *ощущается дорого*.
- Референс-уровень: Linear / Stripe Dashboard — но в теме загородного клуба (зелень + золото).

## 2. Аудитория

- Основная: менеджеры/операторы клуба — power-users, весь день, клавиатура, плотные данные.
- Вторичная: инструкторы (`MySchedule`, `TrainersSchedule`), стойка (`TeeSheet`, `Bookings`).
- Зритель демо: Kidanov — первое впечатление обязано читаться как «реальный premium-продукт».

## 3. Визуальное направление

Ведущая семья: **refined «club instrument»** (НЕ cinematic, НЕ 3D, НЕ brutalist).
Одно слово-настроение: **«fairway at dusk»** — глубокая зелень + тёплый металл.

- Эволюция существующей айдентики: гольф-зелёный `#155E3F` + шампань-золото `#C9A961` + тёплый stone.
- Сдвиг: плоская светлая админка → слоистый, тихий, дорогой инструмент.
- **Тёмная тема — первоклассная** (спроектирована, а не инверсия светлой).
- Золото — **сигнал премиума, дозированно** (активные состояния, KPI, фокус; не везде).

## 4. Анти-генерик правила (жёсткие)

- ❌ НЕ `slate/zinc + indigo-500`. ❌ НЕ дефолтный shadcn-hero. ❌ НЕ только спиннер при загрузке.
- ❌ Золото повсюду (перестаёт быть премиумом). ✅ Золото = редкий акцент.
- ✅ Числа — `tabular-nums`; KPI/заголовки — display-serif **Fraunces** (строго дозированно).
- ✅ Тёмная тема спроектирована отдельно, не инвертирована.
- ✅ У каждого data-экрана есть loading(skeleton)/empty/error/success — никаких «голых» таблиц.

## 5. Карта страниц (21 реальная страница → тиры)

- **Tier A** (демо-критичные, полируем первыми): `Dashboard`, `TeeSheet`, `Bookings`,
  `Customers`, `Analytics`, `Memberships`.
- **Tier B**: `Instructors`, `MySchedule`, `TrainersSchedule`, `EventsCalendar`, `Catalog`,
  `MembershipSales`, `Coupons`, `Trainings`, `Staff`.
- **Tier C** (функциональные, low-touch): `Settings`, `Audit`, `Login`, `ChangePassword`,
  `ServiceEditor`, `InstructorEditor`.
- Для каждой страницы: главный объект, ключевые состояния, плотность (compact/cozy).

## 6. Карта компонентов (эволюция существующего, не с нуля)

- **Поднять существующее:** `Layout` (sidebar+topbar), слой `.card/.btn/.input`,
  `CommandPalette` (оставить — это сигнал премиума), booking-диалоги, `TagInput`.
- **Новое/стандартизировать:** `DataTable` (tabular-nums, sticky header, плотность строк),
  `StatCard`/KPI (Fraunces для числа), `StatusBadge` (статусы бронирований),
  `Skeleton`, `EmptyState`, `ErrorState`, `ThemeToggle` (light/dark), `Toast`.
- Каждый компонент → использование токенов (color/space/radius/state).

## 7. Принципы движения (тонко, instrument-grade — без 3D)

- `motion` для микроанимаций: 120–200ms ease-out на hover/press/menu/dialog.
- GSAP ScrollTrigger — ТОЛЬКО если добавим маркетинговый/login-сплэш (опционально).
- `prefers-reduced-motion` уважается; никакого parallax на data-экранах.

## 8. Data / CRM состояния (ядро premium-saas здесь)

- Жизненный цикл бронирования → цветовые токены: `confirmed / pending / cancelled / noShow / completed`.
- Абонемент: `active / expiring / expired` (+ frozen при необходимости).
- Глобально: loading = **skeleton** (не спиннер), empty = направляющий, error = recoverable, success = toast.
- Типографика чисел: `tabular-nums` везде, где деньги/счётчики/время.

## 9. Адаптация premium-saas (осознанное отклонение от стека пресета)

- Пресет рекомендует Next.js + shadcn; Golf — рабочее 21-страничное Vite-приложение.
- **Решение:** взять *принципы* premium-saas (состояния, плотность, dark-first, tabular-nums,
  дисциплина shadcn-уровня компонентов) на **существующем стеке**. Никакого rewrite фреймворка.
- Токены живут в `design/tokens.json` → вживляются в `tailwind.config.js` (отдельная фаза).

## 10. Чек-лист визуального QA (Golf-specific, расширяет шаблон)

- [ ] Тёмная тема первоклассна на `Dashboard` + `TeeSheet` (не инверсия).
- [ ] У каждой Tier-A страницы есть skeleton/empty/error.
- [ ] Таблицы: `tabular-nums`, sticky header, выбранная плотность.
- [ ] Золото ≤ нескольких акцентов на экран.
- [ ] Статус-цвета бронирований консистентны на `TeeSheet`/`Bookings`/`Dashboard`.
- [ ] Hover/focus-кольца у всех интерактивных; контраст AA в обеих темах.
- [ ] Mobile: sidebar сворачивается, таблицы → карточки/скролл — перестроено, не сжато.
- [ ] playwright-скриншоты против концепт-кадров (когда фаза концептов сделана).
- [ ] LCP < 2.5s, INP < 200ms; длинные таблицы виртуализированы.
